接口约定
单榜最新：api/rank/{slug}.json　·　JS 版（跨域可用）：api/rank/{slug}.js
历史某期：api/history/{slug}/{YYYYMMDD}.json　·　全榜目录：api/index.json
字段：rank_no 名次 · title 剧名 · series_type 类型（漫剧/AI剧）· theme 题材 · episodes 集数 · heat/heat_value 热度（万）· rank_prev 上期名次 · trend_text 趋势 · description 简介
另附旧字段别名 rank / hot / hot_num / 剧名 / 榜单 / date，两套映射都能对上。
漫剧与 AI剧 名次各自独立（各 1–50）。经典榜为周更，热播榜/新剧榜为日更。
